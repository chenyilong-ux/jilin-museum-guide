💡 如何实现「一碰就打开」？（技术说明）
  1. 准备 NFC 标签：购买 NTAG213/215/216 无源标签（约 1–2 元/枚），容量足以写入一个网址。
  2. 写入网址：用手机 App「NFC Tools」或读写器，向标签写入一条 NDEF URI 记录，例如 https://your-domain.com/guide/?id=jilin-meteorite。
  3. 部署网页：把本页部署到服务器（如 GitHub Pages / Vercel / 腾讯云），每个展品对应一个 ?id=xxx 参数。
  4. 贴到展柜：将标签贴在文物说明牌旁（建议加铁氧体吸波材料抗金属干扰）。
  5. 游客一碰：Android 手机原生支持，读到网址自动弹窗打开浏览器；iPhone XS 及以上支持「后台 NFC 读取」，无需开 App 即自动跳转。

补充：如需更沉浸体验，可配合「App Clip（iOS）/ 小程序（微信）」；不支持的机型可用二维码兜底，本页 URL 即二维码内容。
